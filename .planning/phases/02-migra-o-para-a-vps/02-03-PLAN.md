      `current` não existe; `mv -T` sobre symlink é `rename(2)`, atômico.

      `systemctl restart dg2` se os dois hashes diferirem **ou** se

      que é a única operação do deploy capaz de falhar — não vale correr esse risco por uma

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → Caddy :443 | toda entrada não confiável do sistema chega aqui |
| Caddy → processo Node | fronteira entre conteúdo estático e API; a única razão de o Node não estar exposto |
| runner do GitHub → usuário `dg2-deploy` | uma chave privada num CI de terceiro tem acesso de escrita à caixa |
| árvore de releases → `/var/lib/dg2` | reverter código nunca pode reverter dado |
